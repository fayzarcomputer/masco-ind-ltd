⚡ Portal Autofill Chrome Extension

Autofill commercial invoice and EXP data into government customs and foreign buyer portals automatically.

✨ Features: Connects to GET /api/invoices/:id, retrieves full invoice, buyer, and item details, and automatically matches input fields on external web portals without manual copy-pasting.
1. How to Install Extension in Google Chrome
  1. Open Google Chrome and navigate to: chrome://extensions
  2. Enable Developer mode in the top-right corner toggle.
  3. Click the "Load unpacked" button in the top-left.
  4. Select the project folder path:
    .../garments-export-invoice/extension
  5. The "Garments Export Portal Autofill" icon will now appear in your Chrome toolbar!
2. Test the Autofill Engine
Open Simulated External Portal ↗

We have included a simulated external portal that mimics the Bangladesh Bank EXP and Customs clearance declaration form.

  1. Click the button above to open the Simulated Portal Page in a new tab.
  2. Click the FAYZAR Extension icon in Chrome.
  3. Select or type an invoice number (e.g. MIL/MS/1205/2026).
  4. Click "⚡ Autofill Active Webpage".
  5. Watch the fields (Invoice No, EXP No, Buyer Name, FOB Value, Cartons, Pcs, Weights, Port, etc.) populate and glow green!
3. API Endpoint Architecture

The extension communicates directly with the backend endpoint:

GET http://localhost:5000/api/invoices/:id

Response JSON payload includes:

  • Master Details: invoice_no, invoice_date, exp_no, exp_date, total_amount, currency
  • Buyer Data: applicant_name, office_address, country, notify_party, bank_name
  • Logistics: total_carton, total_pcs, total_gross_weight, total_cbm, port_of_loading, port_of_discharge
  • Item Details: po_number, style, hs_code, line_total
